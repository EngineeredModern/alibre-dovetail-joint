# Alibre Dovetail Joint

A practical Alibre Design assembly add-on for creating, editing, and removing sliding dovetail joints.

## Install

1. Close Alibre Design.
2. Download or clone this repository.
3. Double-click `Install.cmd` and approve the Windows administrator prompt.
4. Restart Alibre Design, open an assembly, then choose **Add-on → Sliding Dovetail → Joint Manager**.

## Uninstall

Close Alibre Design, then double-click `Uninstall.cmd` and approve the administrator prompt.

## Version

Current working baseline: v0.7.1.
