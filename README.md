# Alibre Dovetail Joint

A practical Alibre Design assembly add-on for creating, editing, and removing sliding dovetail joints.

## Recommended installation

1. Close Alibre Design.
2. On the [Releases](../../releases) page, download `SlidingDovetailSetup-v0.7.1.1.exe`.
3. Double-click the EXE and approve the Windows administrator prompt.
4. Restart Alibre Design, open an assembly, then choose **Add-on ? Sliding Dovetail ? Joint Manager**.

## Manual installation fallback

Download the source ZIP, extract it, then double-click `Install.cmd` and approve the Windows administrator prompt.

## Uninstall

Close Alibre Design, then use the installer?s entry in Windows **Installed apps**. For a manual installation, double-click `Uninstall.cmd`; it removes both the add-on registration and its folder.

## Version

The add-on working baseline is v0.7.1. Release v0.7.1.1 updates distribution packaging and adds the Windows installer.
